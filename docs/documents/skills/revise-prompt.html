revise-prompt

Bring a vague idea. The skill asks the right questions, then writes a prompt that reads like a creative brief.

skills/productivity/revise-prompt output: prompt text

What it does

revise-prompt turns a rough idea, a partial spec or a vague concept into a finished prompt. It acts as a prompt engineer and creative director, not as a simple expander.

It does not write the final prompt at once. First it finds what is missing or unclear, and it asks you about it. It writes the prompt only when the direction is clear.

When to use it

SituationUse
You have a rough idea for an image, a text or an agent task, and you want a strong prompt for it.revise-prompt
Your prompt gives weak results and you are not sure what is missing.revise-prompt
You only want to fix the grammar or wording of text you already wrote.quill-edit
You want to stress-test a plan or a design, not write a prompt.grilling

Short version: use it when the idea is still unclear, not only the words.

How it works

The skill runs a short clarify loop. It writes only when the loop has nothing important left to ask.

  1. Find gaps. The skill looks for what is missing or ambiguous in your idea.
  2. Ask. It asks one to three focused questions at a time.
  3. Resolve. It points out contradictions. It suggests a stronger direction when that helps.
  4. Write. When the direction is coherent and detailed enough, it writes the final prompt.

The five dimensions

The questions come from five dimensions:

DimensionWhat it asks about
IntentWhat the output must achieve. Functional or expressive?
SubjectMain entities, how they relate, and their hierarchy.
StyleTone and aesthetic: formal or casual, minimal or detailed.
MoodFor example elegant, serious, cinematic, warm, mysterious or energetic.
ConstraintsLength, format, platform and output schema.

What you get

FormatWhenShape
Natural languageDefaultPolished prose, 250–500 words
JSON, YAML, Markdown or structured configOn requestThe same content in the structure you ask for

The result uses dense, precise language, not a list of keywords. It reads like a creative brief or a production spec. The skill gives you the prompt in the chat; it does not write a file.

Here is a short session:

You:    A prompt for a poster about a night market.
Skill:  1. Is it to sell tickets, or to set a mood?
        2. Photo-real, illustrated, or graphic?
        3. Any size or text you must include?
You:    Mood. Illustrated. A3, title "After Dark" only.
Skill:  Warm and busy, or quiet and mysterious?
You:    Warm and busy.
Skill:  [writes a 300-word brief: scene, light, palette,
         composition, title placement, A3 portrait]

Common questions

Why doesn’t it just write the prompt straight away?
A prompt built on guesses keeps the gaps of the idea. A few questions first give a prompt that says what you actually want.
How many questions will it ask?
One to three at a time. It stops asking when the direction is coherent and detailed enough.
Can I get JSON or YAML instead of prose?
Yes. Ask for it. The default is natural language of 250–500 words.
Will it change my idea?
It keeps your core intent. It can suggest a stronger direction, and it fixes contradictions, but you decide.
Is it only for image prompts?
No. The dimensions work for any output: text, images, agent tasks or configs.

It’s working if

  • The skill asks questions before it writes a prompt.
  • Each round has no more than three questions.
  • The final prompt reads like a brief, not a keyword list.
  • The final prompt has no internal contradictions.
  • You still recognise your original idea in the result.

Where it fits

revise-prompt sits between an idea and the tool that runs the prompt. Use it before you send a prompt to an image model, a writing model or an agent.

rough idea → revise-prompt → creative brief → image model / LLM / agent

To polish the English of the finished prompt, use quill-edit. To test a plan instead of a prompt, use grilling.
