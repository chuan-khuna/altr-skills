Skills

One page for each skill in this repository. Each page tells you what the skill does, when to use it, how it works, and what it writes.

Work

Day-to-day work: standups, progress updates, handoffs and project setup.

  • calm-downTurn a brief into a cold-start handoff (assign) or a prioritised battle plan (triage).
  • jira-standup-meetingQuery Jira for a start-of-day summary of your tasks, with recommendations.
  • progress-summaryTurn raw notes or a git log into a short update for Jira or Discord.
  • harden-js-dependenciesSet an install cooldown so new npm versions wait before you can install them.

Productivity

Daily writing and thinking tools that are not about code.

  • write-docWrite a Markdown document from a conversation or from a codebase feature.
  • evergreen-note-writerMake evergreen notes from one or more sources and save them to files.
  • quill-editRephrase and correct English text with British English conventions.
  • revise-promptRefine a rough idea into a clear, ready-to-use prompt, together with you.

Design

Front-end craft: typography, layout systems, and the code that proves them.

  • brockmann-grid-systemAlign an editorial page to a Müller-Brockmann modular grid, and prove 0px adherence.
