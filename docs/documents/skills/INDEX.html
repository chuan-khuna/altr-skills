Skills

One page for each skill in this repository. Each page tells you what the skill does, when to use it, how it works, and what it writes. Point to an underlined term to see its definition, or open the glossary.

Writing

Writing standards and editors for resumes, docs and any prose.

  • resumeWrite and proofread resume text in British English, by the Harvard and Guardian CV rules.
  • technical-writingA four-layer standard for docs, PRs and commits: Diátaxis, Google style, STE and Global English.
  • unslopRemove AI tells from any writing, by a numbered rule list other skills cite.

Install

The plugin altr-skills ships the skills on this page. The marketplace that lists it is altr-local, in .claude-plugin/marketplace.json.

As a Claude Code plugin

To install for your user:

claude plugin marketplace add chuan-khuna/altr-skills
claude plugin install altr-skills@altr-local

To install for a project, add --scope project. Both commands then write to .claude/settings.json in the project. Commit that file, and everyone who clones the project is offered the plugin.

claude plugin marketplace add chuan-khuna/altr-skills --scope project
claude plugin install altr-skills@altr-local --scope project

Skills then run with the plugin name in front, for example /altr-skills:resume.

From a local clone

To install the plugin for this repo only:

mise run plugins

After you change a skill, refresh the marketplace:

claude plugin marketplace update altr-local

To try the plugin for one session without installing it:

claude --plugin-dir .

As plain skills

The skills CLI copies the skill folders into .claude/skills/:

npx skills add https://github.com/chuan-khuna/altr-skills
bunx skills add https://github.com/chuan-khuna/altr-skills

Archived

Skills no longer in use. They live in archived/, and the plugin does not ship them. Their old documents stay in archived/ next to this page.

To try every archived skill for one session, run claude --plugin-dir archived. See archived/README.md to restore one.
