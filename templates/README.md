# Templates

LLM instruction file (`CLAUDE.md`) templates for projects I've developed. Each template captures the conventions, stack decisions, and agent guidance that a Claude Code session needs to work effectively in that project type.

## How to use

Copy the relevant template into a new project root as `CLAUDE.md`, then search for every `<placeholder>` and fill it in. Delete any section that doesn't apply.

## Templates

### `astro/`

- [CLAUDE.md](astro/CLAUDE.md) — General-purpose Astro + Tailwind + shadcn/ui + TypeScript template with placeholders for all project-specific details.
- [matcha_CLAUDE.md](astro/matcha_CLAUDE.md) — Filled-in example based on ALTR's Matcha cafe site (Astro, Cloudflare Pages, content collections for menu items).
