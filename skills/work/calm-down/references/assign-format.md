# Assign Document Format

Output file: `docs/yyyy-mm-dd-topic.{md,html}`

---

## Structure

```
# {Topic}

## Background

{ที่มาที่ไป — why this work exists, what triggered it}

## Current State

{กำลังทำอะไรอยู่ — what is in progress, what has been done so far}

## Tasks

### Task 1: {name}

**Input:** {what is needed to start this task}
**Output:** {what is produced when done}

**Checklist:**
- [ ] {done criterion 1}
- [ ] {done criterion 2}

### Task 2: {name}

**Input:** {what is needed to start this task}
**Output:** {what is produced when done}

**Checklist:**
- [ ] {done criterion 1}
- [ ] {done criterion 2}
```

---

## Rules

- Background and Current State should be 2–5 sentences each — enough context for someone picking up cold
- Each task must have at least one checklist item
- Input and Output should be concrete — paths, formats, states — not abstract descriptions
- Generate immediately after interview; do not preview first
