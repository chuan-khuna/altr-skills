Calm-Down Assignment Paper

Design System · v alpha · DESIGN.md

A quiet, paper-like document theme for calm-down assignment hand-offs. Cool off-white canvas, slate ink, a single slate-blue accent, clear hairline borders, and crisp near-square corners. This page is the design system rendered in its own theme.

Overview

The personality is calm, legible, and structural — a teammate should be able to pick a document up cold and read it like a printed memo. The page floor is a cool off-white (canvas) rather than pure white, giving the surface a soft "paper" quality. There is no decoration, no gradient, and no atmospheric depth — structure is carried entirely by clear 1px hairline borders and near-square corners, never by shadow.

A single slate-blue accent is the only chromatic voltage in the system. It marks the one thing the reader's eye should follow: the active table-of-contents entry, a checked task, a task-number badge. Everything else is slate ink on paper.

The document is a two-column broadsheet: wide content on the left, a narrow sticky table of contents on the right, with equal gutters outside both. On narrow screens the layout collapses to a single column and the TOC folds into a "Contents" disclosure at the top.

Layout

The document is centered in a shell of 1040px with equal outer gutters. Inside: a content column (≤720px) on the left, a 48px gap, and a 220px sticky TOC on the right. The page header spans the full shell width above both columns.

The system is flat — there are no drop shadows anywhere. Depth is conveyed by borders and a single accent rule.

Shapes

The system has no border radius. Every element uses square none (0px) corners — the sharp rectangles reinforce the clear-border, paper-document feel.

Do's and Don'ts

Do

  • Keep the canvas as paper and let 1px hairlines carry structure.
  • Use the slate-blue accent only for interaction, active TOC, and checked items.
  • Set every label, the TOC, and the date in uppercase JetBrains Mono.
  • Keep corners crisp — 0px or 4px, never softer.
  • Keep the header to title + date only.

Don't

  • Don't add drop shadows — depth is borders, never shadow.
  • Don't use pure white as the page floor.
  • Don't introduce a second accent hue.
  • Don't set body in mono, or labels in Inter.
  • Don't give the code block a light theme — the dark island is intentional.
