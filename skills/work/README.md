# Work

Tools for day-to-day work communication — standup summaries, progress updates, and JIRA workflows.

- [jira-standup-meeting](jira-standup-meeting/SKILL.md) — Query Jira for a start-of-day summary of your tasks with recommendations.
- [progress-summary](progress-summary/SKILL.md) — Turn raw notes or git log into a concise update for JIRA or Discord.
- [calm-down](calm-down/SKILL.md) — Two-mode work structuring (Stop → Think → Act): `assign` produces a handoff document a teammate or agent can pick up cold; `triage` is a calming grill that decomposes urgent work into a prioritized battle plan.
