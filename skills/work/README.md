# Work

Tools for day-to-day work — standup summaries, progress updates, JIRA workflows, and project setup.

- [jira-standup-meeting](jira-standup-meeting/SKILL.md) — Query Jira for a start-of-day summary of your tasks with recommendations.
- [progress-summary](progress-summary/SKILL.md) — Turn raw notes or git log into a concise update for JIRA or Discord.
- [calm-down](calm-down/SKILL.md) — Interview the user and produce a structured assignment document for handing off work to a teammate.
- [harden-js-dependencies](harden-js-dependencies/SKILL.md) — Configure an install cooldown so freshly-published npm versions can't be installed until they've been public long enough to be caught.
