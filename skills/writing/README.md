# Writing

Writing standards and editors for resumes, docs and any prose. See [CREDITS.md](../../CREDITS.md) for the source and version of each copy.

- [explainer](explainer/SKILL.md) — Write an article that teaches a topic to a newcomer, in English or Thai, with technical-writing, unslop and a house style.
- [resume](resume/SKILL.md) — Write and proofread resume content in British English, by the Harvard and Guardian CV rules, with technical-writing and unslop.
- [technical-writing](technical-writing/SKILL.md) — Layered technical-writing standard: Diátaxis structure, Google developer style sentences, STE instruction rules and Global English syntax. From [cursor/plugins `pstack`](https://github.com/cursor/plugins/tree/e1cc03121a0e71129a4fb730d7c5528a0a3e43c8/pstack/skills/technical-writing).
- [unslop](unslop/SKILL.md) — Cut AI tells from any writing, by a numbered rule list other skills cite. From [cursor/plugins `pstack`](https://github.com/cursor/plugins/tree/e1cc03121a0e71129a4fb730d7c5528a0a3e43c8/pstack/skills/unslop).

All four set `disable-model-invocation: true`, so they run only when you call them by name.
